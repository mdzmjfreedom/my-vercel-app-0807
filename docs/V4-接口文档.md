# V4 异步导入接口

- `POST /api/import-uploads`：生成受限的私有 Blob 客户端上传凭证，最大 100 MB，仅允许 Excel、Word、PDF。
- `POST /api/import-tasks`：生产环境提交 JSON `blobUrl`、`fileName`、`totalRows`、`rule`/`ruleId`；本地可回退 multipart，返回 `202`、`task_id`、`trace_id`、批次数。
- `GET /api/import-tasks/:taskId`：任务状态、进度、吞吐、降级标识、最近错误和批次状态。
- `GET /api/import-tasks/:taskId/errors?batch=4&error_code=E001&page=1&page_size=50`：行级错误分页。
- `GET /api/import-tasks/:taskId/batches`：批次状态和阶段耗时。
- `GET /api/traces/:traceId`：按时间线返回上传、Outbox、Worker、写库事件。
- `GET /api/traces?task_id=&trace_id=&file_name=&batch=&row_from=&row_to=&error_code=`：多条件检索关联任务。
- `GET /api/import-monitor/summary`：吞吐、队列积压、阶段 P50/P95/P99、错误分布。
- `POST /api/import-worker/job`：QStash 签名回调入口，消息体为 `{ "outboxId": "evt_..." }`；生产环境必须通过 QStash 签名校验。
- `GET /api/import-worker?limit=100`：Outbox 恢复扫描入口，仅供 Vercel Cron 调用；由 `CRON_SECRET` 保护，Hobby 计划按每日恢复任务配置。
